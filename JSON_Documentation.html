1. Overview — Top-level Structure

The file results.json must conform to schema AAVFR_TP1_results v1.1. It contains exactly four top-level keys: 

{
  "schema":    { "name": "AAVFR_TP1_results", "version": "1.1" },
  "team":      { /* group identification */ },
  "reference": { /* aerodynamic conventions and reference quantities */ },
  "cases":     [ /* array of exactly 9 case objects */ ]
}

2. Block Descriptions

object schema

Identifies the schema version used for autocorrection. Must be exactly {"name": "AAVFR_TP1_results", "version": "1.1"}. Do not modify.

object team

Group identification. Contains group_id (string) and members (array of strings with full names).

object reference

Defines the aerodynamic reference conventions: coordinate system description, alpha definition, flow direction, reference area (Sref_m2), reference length (Lref_m), moment reference point, and the unit vectors for the CD, CL, and CM axes — all in body frame, SI units.

All vectors must be unit vectors (norm ≈ 1). No underscore-prefixed fields are allowed in this block as of schema v1.1.

array cases

Array of exactly 9 case objects. Each case contains the aerodynamic coefficients for one specific geometry / method / Mach / alpha combination. The 9 required case_id values are fixed and must match exactly.

6. Coherence Checks C1–C6

The autocorrector verifies 6 rules. All must pass for full credit:

C1
Internal consistency
For every case: CD ≥ 0, all components of force_coeff_body have absolute value < 50, and same for moment_coeff_body.
C2
Sphere symmetry at α = 0
For the three sphere cases at α = 0: |CL| < 1×10⁻³ and |CM| < 1×10⁻³. Expected error is at machine precision (~10⁻¹⁷).
C3
Mach sensitivity — sphere MNM
CD at M=8 must exceed CD at M=2 by more than 1×10⁻³: CD_M8 > CD_M2 + 0.001
C4
Capsule symmetry at α = 0
For capsule cases at α = 0 (MN and MNM): |CL| < 5×10⁻³ and |CM| < 5×10⁻³.
C5
CL grows monotonically with α — capsule MNM
|CL(α=10°)| > |CL(α=0°)| + 1×10⁻³ and |CL(α=20°)| > |CL(α=10°)| + 1×10⁻³
C6
Mesh sensitivity
The relative difference in CD between the coarse and fine capsule meshes at α=10° must be less than 5%: |CD_fine − CD_coarse| / max(|CD_fine|, 1×10⁻⁶) < 0.05

7. What Changed — Schema v1.1 Cleanup

Underscore-prefixed fields removed

The following fields were present in previous outputs but are not part of schema v1.1. They have been removed to avoid autocorrection failures caused by unexpected keys:

FieldWas inReason removed
_n_windward Each case object Internal diagnostic counter. Not in schema v1.1. Removed from build_case_dict.
_n_leeward Each case object Internal diagnostic counter. Not in schema v1.1. Removed from build_case_dict.
_cp_max_mnm Each case object MNM stagnation Cp. Useful for analysis but not required. Removed from build_case_dict.
_sphere_Sref_m2 reference block Sphere reference area. Now passed as a parameter to generate_html() instead of stored in JSON.
_sphere_Lref_m reference block Sphere reference length (2R). Same — passed to HTML generator directly.

The build_reference_block() function now silently filters out any **kwargs whose key starts with an underscore, so legacy callers that pass _sphere_Sref_m2=... will not pollute the JSON output.

The generate_html() function now accepts explicit parameters sphere_sref and sphere_lref for the report display.
