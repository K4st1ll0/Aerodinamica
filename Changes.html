1 · HTML 3D interactivo — Plotly.js

FEAT src/generate_3d_report.py

Se creó el fichero generate_3d_report.py (y la función generate_3d_html()) para producir un reporte HTML completamente autónomo con visualización 3D interactiva usando Plotly.js. El fichero de salida es results/report_3d.html.

Características implementadas

  • Mapa de Cp coloreado por cara (escala viridis) sobre la malla 3D rotable/zoomable.
  • Barra de selectores: Malla, Método (MN / MNM), α, M∞.
  • Pastillas de métricas dinámicas: CD, CL, CM, N-caras, Sref, Lref.
  • Pre-cómputo de toda la base de datos (mesh × model × α × M) en Python y serialización como literal JS dentro del HTML — sin servidor, totalmente standalone.
  • Actualización eficiente con Plotly.react() en lugar de newPlot().
  • Dropdown de M∞ deshabilitado cuando el método es MN (independiente de Mach).

4 · Fix importación en generate_3d_report.py

FIX src/generate_3d_report.py

stl_utils.py importa matplotlib al nivel de módulo. Al importarlo desde generate_3d_report.py, el proceso fallaba en entornos sin display con ModuleNotFoundError: No module named 'mpl_toolkits'.

Solución: Se eliminó la dependencia de stl_utils e implementaron funciones inline (_stl_load() y _face_geom()) usando sólo trimesh y numpy.

def _stl_load(path): import trimesh return trimesh.load(str(path), force="mesh") def _face_geom(mesh): verts = np.asarray(mesh.vertices, dtype=float) faces = np.asarray(mesh.faces, dtype=int) v0, v1, v2 = verts[faces[:,0]], verts[faces[:,1]], verts[faces[:,2]] cross = np.cross(v1-v0, v2-v0) areas = np.linalg.norm(cross, axis=1) / 2.0 normals = cross / (2.0*areas[:,None] + 1e-30) centers = (v0+v1+v2) / 3.0 return {"centers": centers, "areas": areas, "normals": normals}

5 · Fix load_sweep_csv — crash string→float

FIX src/generate_3d_report.py

La función load_sweep_csv() intentaba convertir todos los campos del CSV a float, pero results_mesh_sensitivity.csv contiene columnas de texto (stl, model), causando:

ValueError: could not convert string to float: 'PruebaARD.stl'

Solución: Reemplazado por un helper _cast() que devuelve el valor sin modificar si no es convertible a float.

def _cast(v): try: return float(v) except (ValueError, TypeError): return v return [{k: _cast(v) for k, v in r.items()} for r in rows]

10 · Fix fórmula Rayleigh-Pitot en MNM.py

FIX src/MNM.py

Los exponentes de la fórmula de Rayleigh-Pitot para Cp,max eran γ/(γ+1) y 1/(γ+1). Los correctos son γ/(γ−1) y 1/(γ−1). Con γ=1.4 esto supone un error de ~8.6% a M=8 y ~21% a M=2.

term1 = ((g+1)/2 * M**2) ** (g/(g+1)) # exponente 0.583 ≠ 3.5 term2 = ((1-g+2*g*M**2)/(g+1)) ** (1/(g+1)) # exponente 0.417 ≠ 2.5 p02_over_pinf = term1 * term2 p2_over_p1 = (2*g*M**2 - (g-1)) / (g+1) M2_sq = ((g-1)*M**2 + 2) / (2*g*M**2 - (g-1)) p02_over_p2 = (1 + (g-1)/2 * M2_sq) ** (g/(g-1)) p02_over_pinf = p2_over_p1 * p02_over_p2

Cp,max corregido para M=8: 1.827 (antes 1.670)  ·  M=2: 1.657 (antes 1.312).
