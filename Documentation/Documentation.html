Descripción general

Este repositorio implementa un pipeline de análisis aerodinámico hipersónico basado en Métodos de Inclinación Local. Dados uno o más archivos STL de geometría, el código calcula los coeficientes aerodinámicos CD, CL y CM mediante los métodos de Newton (MN) y Newton Modificado (MNM), genera sweeps en ángulo de ataque y número de Mach, produce gráficas formales y exporta los resultados en CSV, JSON y HTML interactivo 3D.

El diseño separa completamente la configuración (en main.py) de la implementación (en runner.py y los módulos de física). Para analizar una geometría nueva solo hay que añadir su ruta STL a la lista CAPSULES de main.py.

Convenciones de coordenadas y signos

Ejes del cuerpo

x → lateral (envergadura)
y → axial, apunta hacia la popa
z → ascendente (normal al plano de simetría)
Escudo térmico en –y
Base / popa en +y
Flujo entrante en +y a α = 0

Ángulo de ataque α

  • α = 0° — flujo frontal sobre el escudo térmico.
  • α > 0° — flujo inclinado hacia +z (morro sube).
  • α < 0° — flujo inclinado hacia –z (morro baja).

Dirección del flujo incidente

V̂∞(α) = [0, cos α, sin α]

A α = 0, V̂∞ = [0, +1, 0] (flujo en +y).

Ejes viento

êD = [0, +cos α, +sin α] ← dirección de arrastre (paralela a V̂∞) êM = [1, 0, 0 ] ← eje de momento (cabeceo, +x) êL = êM × êD ← dirección de sustentación
Nota de implementación: los ejes viento a α = 0 se obtienen con wind_axes(0.0), que devuelve eD = [0, +1, 0]. Hardcodear eD = [0, −1, 0] (convención +y vieja) invertiría el signo de CD.

Signos de los coeficientes

  • CD > 0 — fuerza oponiéndose al avance (hacia adelante del flujo).
  • CL > 0 con α > 0 — fuerza hacia +z (levantamiento).
  • CM > 0 en +x — cabeceo positivo.

Coeficiente de presión por cara

μi = n̂i · (−V̂∞) ← coseno local de incidencia Cp,i = 0 si μi ≤ 0 (sotavento) Cp,i = f(μi) si μi > 0 (barlovento)

Coeficiente de fuerza por cara

C⃗F,i = −(Cp,i · Ai / Sref) · n̂i

El signo negativo expresa que la presión actúa hacia el interior del cuerpo (en sentido opuesto a la normal exterior).

Coeficiente de momento por cara

C⃗M,i = (r⃗i − r⃗ref) × C⃗F,i · Sref / (Sref · Lref)

Longitudes de referencia

GeometríaSrefLrefrref
Cápsula Extx × Extz (sección frontal XZ) Exty (longitud axial) Centroide geométrico ponderado por área
Esfera π R² 2R Origen (0, 0, 0)

El radio de la esfera se obtiene como R = sqrt(A_total / 4π), donde A_total es la suma de áreas de todos los triángulos.

Fundamento matemático

Método de Newton (MN)

Aproximación de alta velocidad. El coeficiente de presión en una cara de barlovento es proporcional al cuadrado del seno del ángulo de incidencia local:

Cp = 2 μ² (μ = n̂ · (−V̂∞), μ > 0) Cp = 0 (μ ≤ 0, sotavento)

En el límite M → ∞ con γ → 1, Cp,max = 2. El método MN no depende del número de Mach — es puramente geométrico.

Método de Newton Modificado (MNM)

Escala el coeficiente de Newton con el Cp,max real de punto de estancamiento detrás de una onda de choque normal, calculado mediante las relaciones de choque de Rankine-Hugoniot y la fórmula de presión total:

Cp,max = (2 / (γ M²)) · (p02/p∞ − 1)

donde la relación de presiones totales:

p02/p∞ = [(p2/p1) · (p02/p2)] = [ (2γM² − (γ−1))/(γ+1) ] · [ 1 + (γ−1)/2 · M₂² ]^(γ/(γ−1))

La distribución de Cp sigue la misma forma geométrica que el MN, pero escalada:

Cp = Cp,max · μ² (μ > 0) Cp = 0 (μ ≤ 0)

Para una esfera perfecta, la distribución teórica sobre el ángulo φ desde el punto de estancamiento es exactamente Cp,max · cos²(φ), dado que cos(φ) = μ por definición de φ.

Ángulo φ para las gráficas de distribución de Cp

El ángulo φ se define como el ángulo polar desde la dirección de estancamiento, con signo tomado del componente z de la normal:

μi = clip(−ny,i, −1, 1) ← cos del ángulo de incidencia (α = 0) φi = sign(nz,i) · arccos(μi) ← en [−180°, +180°]

Esta definición garantiza que cos(φi) = μi exactamente, de forma que los puntos de la esfera caen sobre la curva teórica Cp,max·cos²φ. La cápsula, al tener geometría no esférica (escudo plano, hombro cónico, base), no sigue esa curva — esa desviación es precisamente la información de interés.

Nota: proyectar la normal al plano y-z antes de tomar el ángulo [arctan2(n_z, −n_y)] introduce error para caras con nx ≠ 0 porque cos(φ_proyectado) ≠ μ. Por eso se usa la definición basada en arccos(μ).

Pipeline de ejecución

El orden interno de run_pipeline es el siguiente:

  1. Carga de geometría de la esfera — STL, geometría de caras, referencias (S_ref, L_ref, R).
  2. Sweep esfera — sweep Mach MNM para la esfera (validación).
  3. Validación vs MATLAB — comparación de CD con datos de referencia.
  4. Bucle sobre cápsulas — para cada STL en CAPSULES:
    1. Carga de geometría y referencias.
    2. Sweeps MN y MNM en alpha.
    3. Sweep Mach MNM a α = 0.
    4. Guardado de CSVs en csv/{nombre_stl}/.
    5. Gráficas de coeficientes en Plots/{nombre_stl}/.
    6. Gráficas de barlovento/sotavento y multi-Mach.
    7. Mapa de Cp 3D.
  5. Sensibilidad de malla — corre MN para cada malla en MESH_STLS, genera CSV y gráficas comparativas.
  6. Distribución de Cp — 4 gráficas de Cp vs φ (esfera y cápsula × MN/MNM) a α=0.
  7. Ensamblado de casos — construye results.json con los 9 casos del informe.
  8. Exportación HTML — report.html (tabla) y report_3d.html (visor 3D interactivo).
La primera cápsula de la lista CAPSULES actúa como cápsula principal: sus resultados alimentan los casos del informe, el mapa de Cp 3D y el visor HTML. Las cápsulas adicionales generan sus propias salidas de forma independiente.

Añadir una cápsula nueva

El pipeline está diseñado para ser completamente reproducible con nuevas geometrías. Los pasos son los siguientes:

  1. Colocar el archivo .stl en cualquier ruta accesible (por ejemplo data/Capsula_2/nueva.stl).
  2. Abrir src/main.py y añadir la ruta a la lista CAPSULES:
"CAPSULES": [
    DATA_DIR / "Capsula"   / "ARD_fine.stl",
    DATA_DIR / "Capsula_2" / "nueva.stl",    # ← nueva cápsula
],
  1. Ejecutar python src/main.py.

El pipeline generará automáticamente:

  • results/csv/nueva/ con todos los CSVs de sweeps.
  • results/Plots/nueva/ con todas las gráficas de coeficientes.
La primera cápsula de la lista sigue siendo la "cápsula principal" que alimenta el informe HTML y results.json. El resto se analiza independientemente sin afectar esos archivos de resumen.

Requisitos de la malla STL

  • Malla triangular cerrada (preferentemente watertight).
  • Normales exteriores coherentes (winding consistente).
  • Escudo térmico orientado hacia –y (el flujo llega en +y a α=0).
  • Unidades: milímetros (igual que la ARD de referencia).
